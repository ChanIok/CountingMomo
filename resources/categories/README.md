# 1440×5760 分类导航资源

用于 `scan-all`，由用户实机通过 30/30 的 Python 导航原型迁移。原型记录：
`prototype/results/categories_20261029_075458_674907`。

原型清单为普通 8 类、饰品 15 类、妆容 7 类。正式 C++ 按用户决定，将全妆、肤色的
`skip_reason` 设为非空：不点击、不扫描，实际执行 28 类，不判断空分类。两个图标仍保留，
供子列表位置推断及向上定位首图标使用；展开妆容后直接点击底妆。

`categories.json` 的 `settings` 保存导航采样区、鼠标停放点、匹配阈值及批量滚动参数；
`groups` 保存菜单顺序、父入口与子类。`image` 相对于 JSON 所在目录。
`crop` 与 `source_point` 只描述模板裁图和按钮中心的关系，不是运行时固定点击坐标。

PNG 与原型一致，来源及裁图坐标见
[`prototype/category_templates`](../../prototype/category_templates/README.md)。
初始来源为用户提供的 SpinningMomo 截图；项圈、手套改取原型失败留图中的清晰图标。
标题截图已确认项圈、臂饰等名称。

图标定位、漏识别保护及批量滚动规划共用此边界，先将美瞳滚到清晰区再匹配。
