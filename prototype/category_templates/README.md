# 分类导航图标

`categories.json` 按菜单顺序列出 8 个普通分类、15 个饰品子类和 7 个妆容子类。两个父入口只用于展开，不计入 30 个末级分类。名称是导航标签，实际标题由运行时截图供人工核对。腕饰与手套之间的圆环带星形图标是项圈，已由 `categories_20261029_074535_325125/06_arm_accessories_title.png` 确认。

PNG 是用户提供的 1440×5760 原图中的图标裁图，保留原生尺寸。配置记录来源文件、裁图矩形（右下边界不包含）和对应按钮中心。程序在当前画面重新寻找图标，不把来源坐标当作运行时点击坐标。

全妆、肤色的 `sample_empty` 只记录当前样例为空，不跳过访问，也不宣称运行时仍为空。

分组子列表内联展开，不自动移动父按钮。饰品的展开区以下方妆容入口为界；妆容没有后继入口，`viewport_bottom_offset: 418` 取自其完整展开样例（父按钮中心约 y=306，可读区下界约 y=724）。父入口尚在侧栏下部时，先在 `outer_scroll_point: [229,126]`（顶部首个槽位）滚动外层菜单，再操作内层。此点在展开子列表上方，不会悬停正在定位的父按钮；布局参考为用户提供的 `20261029_073110_343.jpg`。

子类行距为 68px，用于从已定位图标推算目标所在位置、计算滚动步数及发现漏识别，不用于代替点击前的图标定位。手套模板已改取 `categories_20261029_074535_325125` 中 y=420 的完整、非悬停、非渐隐图标，不再使用原图顶部渐隐状态；戒指也改取 `20261029_064222_019.jpg` 中 y=396 的清晰状态，避免下部渐隐。用户运行 `categories_20261029_075100_754507` 已完成饰品 15/15，标题核对确认第 13 项为“臂饰”，原“腰饰”标签已更正，图标和点击位置不变。

当前固定布局的滚动率为 24px/格，依据用户实机日志中外层父入口每格上移 24px，以及内层腕饰两格从 y=572 移到 y=524。展开时目标父位置分别为饰品 y=222、妆容 y=306，取自完整展开样例。脚本按距离计算一次发送的格数，不逐轮学习；内层一次最多移动可读高度减一行，保留图标重叠。

`collars.png`、`gloves.png` 来自失败留图中的清晰图标，`source_root: results` 表示来源相对于 `prototype/results/`，其他模板仍读取传入的 SpinningMomo 原图目录。重新生成这些模板时需要保留对应结果目录；运行导航只需要已附带的 PNG。
