# 盘点吧大喵 · CountingMomo

《无限暖暖》Windows 图鉴拥有状态采集工具，自动切换分类、滚动读取，生成可复制到其他应用的 JSON。

> 当前版本仍在开发中，完整扫描流程尚未完成实机验证。

## 使用

需要 Windows 10 2004 或更高版本，以及支持 WGC、D3D11 Feature Level 11.0 和捕获纹理着色器读取的环境。
解压到可写目录，保留 `CountingMomo.exe` 与 `resources/` 的相对位置，运行程序。
程序需要管理员权限，普通启动时会请求 UAC 授权；取消授权则退出，已经以管理员身份启动时不重复请求。
同一 Windows 登录会话只运行一个实例，即使从不同解压目录启动也会唤起已有主窗口，不再次请求提权。

1. 在游戏中打开 **美鸭梨 → 博物图鉴 → 检索**，清除筛选并使用默认排序。
2. 收起左侧的 **饰品**、**妆容** 分组，将分类栏滚到顶部。
3. 点击 **开始扫描**。程序会最小化主面板，激活游戏，跳过默认选中的 **套装**，从 **发型** 开始依次扫描 27 个分类；采集范围不包含套装、全妆和肤色。
4. 完成后点击 **复制结果**，或选择 **另存 JSON**。关闭程序前请取走结果。

扫描会临时将游戏调整为 **1440×5760 无边框竖屏**，默认在结束后恢复原窗口。
分类菜单上部（客户区 y=728 以内）须在显示器内且无遮挡。扫描期间不要手动操作游戏或切走焦点；按 **F8** 停止，关闭程序会先等待任务收尾。

扫描进度浮窗固定在游戏所在显示器的工作区右下角，可覆盖游戏但不抢占焦点；结束通知在同一位置显示 12 秒。

结果只保留在当前进程内，不自动保存业务文件或覆盖剪贴板。失败或停止时不提供本次完整结果，
此前的成功结果仍可通过 **复制上次成功结果** 取回。

## 结果

```json
{
  "hair": [0, 1, 0, 1],
  "dresses": [1, 0, 0, 1]
}
```

`1` 为拥有，`0` 为未拥有，问号物品记 0 并保留位置。每个数组从分类第一件开始，逐行从左到右排列；
接收方用同版本、同分类、按图鉴默认顺序排列的物品 ID 表配对。扫描器不读取数据库或识别名称。
英文分类键及扫描顺序见 [导航模块](src/features/navigation/navigation.cpp) 中的三个 `*_categories` 静态数组。

## 问题排查

- 无法自动激活时，在提示期限内 Alt+Tab 切回游戏。
- 主面板显示简明失败原因。扫描任务失败或有收尾警告时，诊断保存在程序目录下的 `data/diagnostics/<时间戳>/`：`report.json` 记录版本、阶段、分类、采集数量、完整错误与警告，已有现场图片保存为 `failure.png`。
- 需要反馈问题时，通过 **打开诊断** 取得该目录；成功但有警告时，可从设置页打开。分享前检查现场图片，其中包含游戏画面。
- 设置页的 **GitHub 仓库** 打开项目主页，用于查看源码或反馈问题。
- 正常成功和无收尾异常的主动停止不生成诊断；不保存过程日志、成功截图或半成品数组。进程直接崩溃或被强制结束时，可能没有诊断报告。
- 无法创建数据目录或保存设置时，检查目标路径的写入权限，或将整个程序目录移到可写位置后重试。
- 窗口恢复失败时，通过游戏设置恢复窗口模式与尺寸；已完整取得的结果仍可复制。

## 便携数据与更新

首次运行自动在 `CountingMomo.exe` 同级创建 `data/`，设置保存在 `data/settings.json`，异常诊断按需保存在 `data/diagnostics/`。
数据位置始终以 exe 所在目录为准，不受快捷方式或终端的工作目录影响，不使用 AppData，也不自动读取或迁移旧 AppData 数据。

搬迁或备份时携带整个程序目录；覆盖更新时保留原有 `data/`，替换 exe 和 `resources/`。
如果将新版解压到新目录，先关闭旧版，再将原有 `data/` 带到新版目录。删除程序目录即可清理程序自身保存的数据；主动另存到其他位置的结果文件需自行管理。

语言默认按 Windows 显示语言选择：中文使用简体中文，其余使用 English；可在设置中切换并保存。

## 构建

需要 clang-cl、支持 C++23 的 MSVC 标准库、Windows SDK、xmake、vcpkg 和 Node.js。在仓库根目录执行：

```powershell
xmake f -p windows -a x64 -m release
xmake build CountingMomo
xmake package                # 仅打包已有 Release，不触发构建
```

程序输出到 `build/windows/x64/release/`，发行包输出到 `dist/CountingMomo-<时间戳>/`。
发行包不包含本机 `data/`，用户数据由程序运行时创建。
布局和识别参数编译在所属功能模块内，程序与素材须一起更新；对外分发前确认所附游戏界面素材的使用与再分发权限。

开发约定见 [AGENTS.md](AGENTS.md)，状态与流程归属见 [架构说明](docs/ARCHITECTURE.md)，文本维护与 C++ 用法见 [i18n 开发说明](docs/I18N.md)。
